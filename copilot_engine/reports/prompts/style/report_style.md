Headings:

Use H1 for title.

Use H2 for sections.

Use H3 only for subsections.

Paragraphs:

Maximum four lines.

Lists:

Recommendations should use bullets.

Numbers:

Always display percentages with %.

Dates:

Use DD MMM YYYY.

Language:

Professional.

Simple.

Readable.

Avoid jargon.

No emojis.

No marketing language.

No exaggerated praise.
